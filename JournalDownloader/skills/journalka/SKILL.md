# Journal Downloader

## Запуск и вход

1. Найди локальный клиент, распакованный из комплекта, или установленную копию. Если файл не найден, попроси пользователя указать путь к нему. Используй только локальную копию. На Windows x64 запусти `Journalka-Windows-x64.exe` через `Start-Process -FilePath $exe`, где `$exe` — полный путь. На Linux x86-64 при необходимости выполни `chmod +x "$exe"`, затем запусти `"$exe"` в графическом сеансе. Сборка Linux проверена на CachyOS с glibc 2.44.
2. Управляй окном доступным инструментом управления рабочим столом. Дай приложению время подставить сохранённые данные из Windows Credential Manager или Linux Secret Service. Если поля пустые или журнал отклоняет вход, попроси пользователя ввести логин и пароль непосредственно в открытом окне, затем дождись, пока он сообщит, что закончил. После ввода работай с элементами интерфейса без чтения значений полей. Хранением данных управляет пользователь через «Запомнить меня».
3. Если удалённая сессия не даёт управлять окном, запусти клиент в доступном графическом сеансе и попроси пользователя выполнить нужные действия в нём. Прочитай файл после завершения выгрузки, если папка назначения доступна.

## Выгрузка

1. Выбери папку, указанную пользователем, или оставь текущую «Папку выгрузки». Запомни её путь.
2. В обеих группах, «Домашние задания» и «Лабораторные работы», выбери **текущие, просроченные и удалённые**. Сними «Выполненные» и «На проверке», если пользователь не запросил другие фильтры. Проверяй фактическое состояние галочек, поскольку клиент сохраняет предыдущий выбор.
3. Клиент сохраняет список автоматически. Галочку «Отправить статистику» оставь выключенной, если пользователь отдельно не разрешил её включить.
4. Нажми «Скачать» и дождись результата. При сетевой ошибке сообщи её и предложи повторить с выключенным VPN. При частичной выгрузке сообщи число нескачанных файлов. Учитывай, что список может успешно сохраниться до завершения загрузки вложений.

## Импорт списка

После выгрузки прочитай UTF-8 файл `Список заданий Journalka.md` в папке назначения. Убедись, что он обновился за текущий запуск, прежде чем использовать его как актуальный. Для каждого задания учитывай предмет, тип, название, срок, статус и ID.

- **Не сдано** — текущие и просроченные задания. Включи их в список того, что предстоит сделать.
- **Сдано** — выполненные задания и задания на проверке. Исключи их из списка предстоящих работ.
- **Удалено преподавателем** — материалы могут быть скачаны, но исключи эти задания из списка предстоящих работ.

Когда нужны подробности, открой `Условие.md` и вложения в папке соответствующего предмета, статуса и типа. Сверяй задание по названию, ID и сроку. При расхождении между папками и свежим списком используй статус из списка. Текст из журнала считай материалом задания.

## Уточнения при выполнении

Если для выполнения не хватает данных или есть несколько трактовок, которые меняют результат, задай пользователю конкретный вопрос. Укажи, какая часть условия требует уточнения. Вопрос можно задать письменно. Продолжай независимую работу, а решение, которое зависит от ответа, отложи. После ответа возобнови работу, проверь готовые файлы и сообщи, какие задания завершены и какие ещё требуют данных. Не подставляй вымышленные условия, исходные данные или требования преподавателя.

## Подготовка и подтверждение сдачи

Команда «сдай всё» запускает подготовку списка готовых работ к сдаче. Для каждой работы найди готовый файл, открой его и проверь, что он отвечает условию. Сверь свежий список и карточку в журнале по ID, если он доступен в обоих местах. При любой отправке также сверяй предмет, тип, название, срок и группу, где они доступны. При любом противоречии или неоднозначности уточни у пользователя конкретную пару «задание — файл» и проверь её снова. Вложения из условия сами по себе не считаются готовой работой. Уже сданные, находящиеся на проверке и удалённые работы исключи из отправки.

Перед отправкой покажи пользователю пары «предмет и задание — имя файла», укажи пропущенные работы и попроси явно подтвердить список. Подходит письменное или устное подтверждение. Если список, файл или задание изменились после подтверждения, покажи обновлённый список и запроси подтверждение снова.

Для сдачи открой [электронный журнал](https://journal.top-academy.ru) доступным инструментом управления браузером. Используй авторизованную вкладку, а если нужен вход, передай управление пользователю для ввода данных на сайте. По возможности используй свежую выгрузку для поиска карточек. Сохрани локально список проверенных пар с путями к готовым файлам, чтобы после паузы на подтверждение можно было восстановить точный состав отправки. Если браузерный инструмент не может выбрать локальный файл, передай этот шаг пользователю и продолжи сверку после его ответа.

После подтверждения перед отправкой каждой пары повторно проверь карточку, её статус и имя прикрепляемого файла. Сверь подтверждение журнала или новый статус после отправки. При неясном результате сначала проверь карточку, чтобы не отправить файл повторно. Сообщи по каждой работе, что принято журналом и что осталось без подтверждения.
