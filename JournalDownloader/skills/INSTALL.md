# Journal Downloader

1. Распакуйте архив. Скопируйте папку `journalka` целиком в `~/.codex/skills/` на Linux или `%USERPROFILE%\.codex\skills\` на Windows. Если задан `CODEX_HOME`, используйте папку `skills` внутри него.
2. Откройте новый чат и напишите `$journalka скачай задания и покажи, что осталось сделать`. В архиве есть клиент Journal Downloader для Windows и Linux. Его можно открыть вручную или указать ИИ полный путь к распакованному клиенту. На Linux при необходимости добавьте право запуска через `chmod +x Journalka-Linux-x64`.
3. Чтобы поручить выполнение, укажите задания. Чтобы сдать готовые работы, напишите `$journalka отправь всё` и подтвердите проверенный список файлов.

Для работы с клиентом нужен доступ ИИ к рабочему столу, для сдачи — управление браузером с возможностью выбрать локальные файлы. Если эти действия недоступны в вашей сессии, скилл попросит выполнить нужный шаг вручную. Логин и пароль вводятся в окне клиента или на сайте журнала.
