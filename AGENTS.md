# Journal Downloader на другом компьютере

Когда пользователь просит «подтяни Journal Downloader с GitHub», используй публичный репозиторий [gnidus-stuff](https://github.com/Gnidus-pozhovanny/gnidus-stuff). Найди существующую копию, проверь `git status --short` и адрес `origin`, затем обнови ветку `main` через `git pull --ff-only origin main`. Если копии нет, клонируй репозиторий в рабочую папку пользователя. Если обновлению мешают локальные правки, сохрани их и сообщи о конфликте.

Открой `JournalDownloader/skills/INSTALL.md`. Для использования GUI возьми архив [Journalka-AI.zip](https://github.com/Gnidus-pozhovanny/gnidus-stuff/releases/download/journalka-desktop-2026-11-13/Journalka-AI.zip) из релиза этого же репозитория, распакуй его и подключи скилл по инструкции. Если архив уже распакован, используй локальную копию. Скачивание архива относится к явному запросу на установку или обновление, а при обычном запуске скилл использует локальный клиент.


После установки проверь, что файл скилла лежит в каталоге навыков Codex и GUI запускается на текущей ОС. Сообщи путь к клиенту и результат проверки. Пользователь вводит данные журнала непосредственно в клиенте или на сайте.
